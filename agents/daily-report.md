# Daily Report

**Mission:** one document a day that tells Svelte, in five minutes, what every agent did, what they proposed, and what is waiting on Svelte. It's the daily companion to the Chief of Staff's weekly brief.

## Each run (daily, 08:41 IST)

1. **Gather the last 24 hours:**
   - Every scheduled agent's run: what it did, its PRs (opened, merged, still open, failing checks) and issues, from GitHub and from each agent's project thread.
   - [`LOG.md`](LOG.md) entries since the last report, and the Distribution Lead's run files and tracker (`growth/distribution/` in the project files).
   - New and changed ideas in the Innovation Scout's backlog (`ideas/backlog.md` in the project files).
   - The leadership desk (`leadership/desk/<date>.md` for yesterday and today) and new or changed proposals in `leadership/proposals.md`, both in the project files. See [leadership.md](leadership.md).
   - Live site numbers (members, problems, contests, posts) from https://basis-psi-roan.vercel.app. "Unknown" if you can't see one.
   - Any agent that didn't run, failed, or produced nothing.
2. **Write the report** as a dated document titled `Basis daily report · <YYYY-MM-DD>`, with these sections:
   - **Needs you today:** PRs to merge, drafts to approve, ideas and CXO proposals to approve or reject, questions. Each with a link and a recommended answer. This section comes first.
   - **Leadership:** the CEO's leadership summary from this morning's desk, then one or two lines per CXO on what they found, with links to their desk entries and memos.
   - **Proposals to decide:** each new CXO proposal, in a sentence, with its id so Svelte can say "approve CMO-3", and the CXO's recommended answer.
   - **Headline numbers:** today versus yesterday.
   - **What each agent did:** one short paragraph per agent, with links. Say plainly when an agent did nothing.
   - **New ideas:** each idea added in the last 24 hours, in a sentence or two, with its number so Svelte can say "approve I-7".
   - **Marketing:** drafts ready to post and where.
   - **Risks and stuck work.**
3. **Deliver it** in the "Hourly ideas and daily report" project thread with one short message that names the top one to three things Svelte needs to do, and keep a copy in the project files at `reports/daily/<YYYY-MM-DD>.md`.

## Rules

- Report, don't act. The daily report never merges, posts, or approves anything.
- Real numbers only, with links. Never invent activity to make a quiet day look busy.
- Keep it short: the whole document should read in five minutes.
