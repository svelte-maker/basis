# Telegram kit (optional)

Add this only once WhatsApp is running smoothly. It mirrors the WhatsApp announcements for people who live on Telegram (common in CFA and Indian finance study groups).

## Create it

1. Telegram → pencil / **New message** → **New Channel**.
2. Name: **Basis Finance Community**. Description: see below. Add the logo. **Next**.
3. Channel type: **Public**, link `t.me/basisfinance` (or the closest free name).
4. Skip adding subscribers. Don't add people who haven't asked.
5. Channel info → **Edit** → **Discussion** → **Add a group** → create **Basis Finance Chat**. Comments on each channel post then go to this group.
6. In the discussion group: **Permissions** → turn off *Add members* and *Pin messages* for members; turn on **Slow mode** (30 s). Enable **Aggressive anti-spam** if offered.
7. Pin the welcome post below.
